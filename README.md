# Измерение скорости HTTP-загрузки

Консольная утилита (тестовое задание): делает 10 последовательных GET-запросов к указанному адресу, дожидается полного ответа на каждый и выводит среднее время запроса, суммарный объём скачанных данных и скорость скачивания.

Один файл `benchmark.py`, только стандартная библиотека, Python 3.10+, ноль зависимостей.

## Запуск

```bash
python3 benchmark.py 'https://speed.cloudflare.com/__down?bytes=5000000'
```

Реальный вывод этой команды:

```text
Скачано: 47.7 МиБ (50 000 000 байт)
Среднее время запроса: 0.141 с
Скорость скачивания: 33.828 MiB/s
```

Прогресс по каждому запросу печатается в `stderr` (итог — в `stdout`, как у `curl`):

```text
Запрос 1/10: 200, 4.8 МиБ за 0.151 с
Запрос 2/10: 200, 4.8 МиБ за 0.117 с
...
Запрос 10/10: 200, 4.8 МиБ за 0.136 с
```

Справка по флагам: `python3 benchmark.py --help`.

## Флаги

| Флаг | По умолчанию | Описание |
| --- | --- | --- |
| `URL` (позиционный) | — | прямой http(s)-адрес ресурса, например тяжёлой картинки; query-строку лучше заключать в кавычки |
| `--count N` | 10 | число запросов (по условию задачи — 10) |
| `--timeout SEC` | 30 | таймаут сетевых операций и порог проверки времени при чтении тела |
| `--json` | — | итог одним JSON-объектом в `stdout` (для автоматизации); прогресс уходит в `stderr` |
| `--version` | — | версия утилиты |

## Единицы измерения

Скорость выводится в **MiB/s** — мегабайтах в секунду по стандарту IEC: 1 MiB = 1 048 576 байт (2²⁰). Объём печатается дважды: человекочитаемыми двоичными единицами (КиБ/МиБ/ГиБ) и точным числом байт. Для сравнения с тарифами провайдера в битах: 1 MiB/s ≈ 8.39 Mbit/s.

## Как считаются метрики

- **Время запроса** — монотонный таймер (`time.perf_counter`) от отправки GET до получения последнего байта тела. Каждый запрос идёт по новому соединению, поэтому в замер входят DNS, установка TCP и согласование TLS (для HTTPS) — то, что реально почувствует пользователь при первом обращении.
- **Переадресации** (301/302/303/307/308) следуются автоматически, до 5 подряд; их время входит в замер, объёмом считается тело финального ответа.
- **Среднее время** — сумма времён всех запросов, делённая на их число.
- **Объём** — сумма длин прочитанных тел ответов, без HTTP-заголовков и накладных расходов TCP/TLS. Перед каждым запросом отправляется `Accept-Encoding: identity` — сервер просят не сжимать тело; если он всё же сжимает, учитываются полученные (сжатые) байты.
- **Скорость** = суммарный объём / сумма времён запросов.

## Надёжность

- **Обрыв тела обнаруживается**: если ответ обещал `Content-Length` N, а получено меньше — запрос считается ошибочным. Для chunked-ответа HTTP-клиент проверяет завершение по конечному блоку. Если же тело ограничено только закрытием соединения, штатное завершение неотличимо от обрыва.
- **Таймаут** применяется к операциям сокета. Суммарное время, включая переадресации, дополнительно проверяется после чтения каждого блока тела. Это не жёсткий предел: проверка может сработать позже, если чтение блока затянулось.
- Тело читается блоками по 64 КиБ и **не записывается на диск**; потребление памяти пропорционально блоку, а не размеру файла.
- На ошибке (HTTP 4xx/5xx, сеть, обрыв, таймаут, петля переадресаций) измерение прекращается: в `stderr` печатается номер запроса и причина, скрипт завершается с кодом 1 и **не выдаёт «частичных» метрик**.
- **Автоповторов нет**: ретраи исказили бы измерение — успешные повторные попытки замаскировали бы реальные просадки.

## Коды возврата

| Код | Значение |
| --- | --- |
| 0 | измерение прошло, метрики выведены |
| 1 | ошибка сети / HTTP / обрыва тела — прервано на указанном запросе |
| 130 | прервано пользователем (Ctrl+C) |
| 2 | ошибка в аргументах командной строки |

## Пример автоматизации

## Соответствие заданию

- принимает адрес, к которому стучаться — позиционный аргумент `URL`;
- 10 запросов последовательно, с ожиданием полного ответа на каждый — по умолчанию `--count 10`, запрос завершается только после последнего байта тела (с детекцией обрыва);
- считает среднее время запроса и общий объём скачанных данных — да;
- печатает в консоль скорость скачивания — `MiB/s`, единицы описаны выше;
- README с инструкцией по запуску — этот файл.
