# Измерение скорости HTTP-загрузки

Утилита делает 10 последовательных GET-запросов к одному адресу и выводит среднее время запроса, общий объём скачанных данных и скорость. Нужен Python 3.10 или новее. Сторонних зависимостей нет.

## Запуск

```bash
python3 benchmark.py 'https://example.com/'
```

Для измерения на файле передайте его прямой HTTP(S)-адрес. URL с параметрами лучше заключить в кавычки. Для справки выполните `python3 benchmark.py --help`.

## Как считаются метрики

- **Время запроса** измеряется монотонным таймером от начала GET до полного чтения тела. Каждый запрос использует новое соединение, поэтому в замер входят DNS, TCP и, для HTTPS, TLS.
- **Объём** — сумма байтов тел всех ответов. HTTP-заголовки, разметка chunked и накладные расходы TCP/TLS в объём не входят. Скрипт запрашивает `Accept-Encoding: identity`. Если сервер всё же кодирует тело, учитываются полученные байты до распаковки.
- **Среднее время** — сумма времён десяти запросов, делённая на десять. **Скорость** — суммарный объём, делённый на сумму времён. Единица вывода — MiB/s (1 MiB = 1 048 576 байт). В скорость входят ожидание ответа и загрузка его тела.

Тело читается блоками по 64 КиБ и не записывается на диск. Автоматических повторов и переходов по перенаправлениям нет. На сетевой операции действует таймаут 30 секунд ожидания. При HTTP-ошибке или обнаруженном обрыве скрипт сообщает номер запроса и завершается с кодом 1 без итоговых метрик. Для тела, окончание которого обозначается только закрытием соединения, HTTP не позволяет отличить штатное закрытие от преждевременного.
